# Pilot Comprehension Test Protocol (Prompt 80)

**Status:** Pre-E10 Non-Public Pilot  
**Target:** ISL-Competent Evaluators (n=3 to 5)  
**Objective:** Identify and fix critical avatar rendering, timing, and articulation errors before formal deployment in the E10 user study.

> [!WARNING]
> Do NOT treat these pilot results as final publication evidence. This protocol is strictly intended for internal iterative improvement of the avatar subsystem.

## 1. Evaluation Methodology

Evaluators will be shown a curated subset of stitched ISL animation sequences generated by the Unity controller. 

For each sequence, the evaluator will be asked to report on the following metrics via a structured digital form (e.g., Qualtrics / Google Forms):

### 1.1 Sign Correctness
*   **Prompt:** "What signs did you observe in this sequence?"
*   **Measurement:** Open-ended textual response. We calculate a localized gloss error rate (GER).
*   **Failure Condition:** > 10% of signs misidentified.

### 1.2 Message Comprehension
*   **Prompt:** "What is the overall meaning of this sentence?"
*   **Measurement:** Semantic similarity grading (0-5 scale) against the ground truth English translation.
*   **Failure Condition:** Evaluator cannot extract the core meaning of the sequence.

### 1.3 NMM (Non-Manual Marker) Correctness
*   **Prompt:** "Were the facial expressions and head movements appropriate for the linguistic context? Did any feel robotic, out of place, or missing?"
*   **Measurement:** Binary Yes/No with a mandatory qualitative explanation if No.
*   **Failure Condition:** Missing grammatical markers (e.g. absent furrowed eyebrows on WH-questions).

### 1.4 Confusing Transitions & Coarticulation
*   **Prompt:** "Did the movement between signs look natural, or did it jump/distort abruptly?"
*   **Measurement:** 5-point Likert scale (1 = Highly Unnatural/Jumpy, 5 = Highly Natural/Smooth).
*   **Failure Condition:** Any score <= 2. Focus on handshape distortion during the transition window.

### 1.5 Unreadable Finger Articulation
*   **Prompt:** "Were the fingers clearly visible and accurately positioned during holds?"
*   **Measurement:** Qualitative flag.
*   **Failure Condition:** Collapsed fingers, clipping through the avatar's body/face, or locked metacarpal joints.

## 2. Iteration Loop (Pre-E10)

1.  **Run Pilot:** Execute protocol with 3-5 ISL-competent evaluators.
2.  **Triangulate Issues:** Aggregate responses. If a specific gloss fails comprehension across multiple evaluators, flag it.
3.  **Avatar Fixes:** 
    *   If transitions fail, tweak AHDR envelope curves in `transition_engine.py`.
    *   If fingers fail, patch `retargeting_verifier.py` limits or re-bake the source clip in the library.
    *   If NMM fails, tweak intensity multipliers in `nmm_controller.py`.
4.  **Re-Verify:** Run `avatar_validation_suite.py` to ensure patches do not introduce new regressions.
5.  **Lock Pipeline:** Once all fatal comprehension errors are resolved, freeze the avatar subsystem for E10 formal testing.
